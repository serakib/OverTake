# 🏎️ Overtake

A nostalgic pixel racing experience inspired by the simple joy of classic childhood car games.
Race through the neon track, dodge traffic, collect energy, and chase a higher score.
Simple controls, familiar arcade gameplay, and fast-paced challenges bring back old-school memories.
Built with HTML5 Canvas, CSS3, and JavaScript for a smooth browser-based experience.
